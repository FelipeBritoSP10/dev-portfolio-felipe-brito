Sistema de Gestão de Medicamentos

Java · Estácio

Projeto acadêmico desenvolvido na graduação de Análise e Desenvolvimento de Sistemas (Estácio), focado na aplicação prática de Programação Orientada a Objetos e regras de negócio para saúde.
